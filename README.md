# 15 août, 15h00 : tsunami en mer Ligure

Film 3D interactif de sensibilisation au risque de tsunami sur la Côte d'Azur (Antibes, rade de Villefranche-sur-Mer, Cap Ferrat).

Un séisme en mer Ligure, la mer qui se retire, l'alerte FR-Alert quinze minutes plus tard, puis une vague de 3 mètres. Quatre familles, deux qui font les bons choix et deux qui font les mauvais.

## Voir le film

Ouvrir `index.html` dans un navigateur (Chrome, Edge ou Firefox), puis cliquer sur « Lancer le film ».

Le fichier est autonome : il fonctionne sans installation et sans connexion à un autre site.

## Les bons réflexes

1. Une secousse ressentie en bord de mer suffit : n'attendez pas l'alerte.
2. La mer qui se retire est un signal d'alarme : partez immédiatement.
3. Laissez vos affaires et votre voiture.
4. Montez : hauteurs, ou étages élevés d'un immeuble solide.
5. Ne redescendez pas avant la fin de l'alerte.
